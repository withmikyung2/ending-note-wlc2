# GYA_AMS Google Forms 제작 명세

현재 사용 가능한 도구로는 Google Forms를 자동 생성할 수 없어, 아래 명세대로
**Google Forms에서 직접 만드는 방법**을 안내합니다 (각 폼 5~10분이면 완성됩니다).

## 공통 작업 순서

1. forms.google.com → 새 설문지 만들기
2. 아래 문항을 순서대로 추가 (질문 유형은 표의 "유형" 참고)
3. 우측 상단 스프레드시트 아이콘 → **응답 연결(Link to Sheets)** → "기존 스프레드시트 선택" →
   `GYA_AMS_데이터시트_v0.1` 선택. Forms는 자체 새 탭(예: `설문지 응답 1`)을 만듭니다.
4. GYA Hub 스태프가 주기적으로(권장: 매주) 그 응답 탭 내용을 검토해 본탭(04_출석 등)에 옮겨 적습니다.
   (데이터가 안정되면 Apps Script로 자동 반영하는 2단계 확장을 검토합니다.)
5. 링크는 QR코드로 만들어 각 공부방에 인쇄물로 비치하는 것을 권장합니다 (기존 wlc-note 운영방식과 동일).
